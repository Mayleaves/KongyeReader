# 空叶阅读

本地 TXT / EPUB 阅读器。黑白手绘风，参考「小鸡专注」：白底、粗黑圆角按钮、灰色胶囊，吉祥物是一只黑猫。书、阅读记录和词典都在手机里；2.0.0 起申请联网权限，只用于用户自己填写的 WebDAV 云备份和手动点的「检查更新」，平时不联网。

- 包名 `com.kongye.reader`（1.1.0 及以前用过 `com.kongye.yuedu`）
- 最低 Android 8.0（API 26）

## 功能

- **导入**：系统文件选择器多选；文件管理器“用空叶阅读打开”；其他应用“分享到”（文件或一段文字）
- **TXT**：自动识别 UTF-8 / GBK(GB18030) / UTF-16；去掉开头的整页目录；认不出章节时按约一万字分节。章节标题按下面的顺序认：
  1. “第X章 / 节 / 回 / 话 / 卷”“卷X”“Chapter N”，有两个以上就只认这种
  2. 没有的话，从“一、”“1、”“1.”“(1)”“001 标题”“【标题】”和单独一行的短句里挑一套最像目录的：数量够、彼此隔得开（一章至少几百字），带编号的要大体按 1、2、3 往下排；单独一行的短句要么前后有空行，要么正文都缩进而它顶格
  3. 序章、楔子、尾声、番外、后记这类总是算
- **书籍信息**：首次导入自动识别章节、书名、作者、简介、标签；编辑页点“重新识别书籍”会直接回填信息，TXT 同时按最新规则重分章，保留阅读位置和书签
- **EPUB**：按书脊顺序读正文，用 nav / ncx 目录分章（同一文件多个锚点也会切开），取出封面
- **翻页**：平移、覆盖、上下滚动；点击左右翻页、音量键翻页、沉浸式全屏
- **排版**：字号、行间距、段间距、首行缩进、上下边距、左右边距；两端对齐（自己按行补字间距，见下）
- **字体**：系统默认、霞鹜文楷 GB、仓耳今楷 02
- **纸色与亮度**：白 / 米 / 灰 / 青 / 夜间；“夜间”二级菜单里调亮度、夜间模式、跟随系统
- **长按**：自动选词（成语 / 诗句 > 词语、人名、地名、书中反复出现的人名 > 单字），选区下方弹字典（读音、简单释义；英文给音标和中文释义）；两端把手可拖；复制、字典、分享、全选
- **编辑本章**：参考 Notepad++，段号、当前段高亮、撤销 / 重做、查找替换、状态栏；版式和阅读页完全一样，打开时正在读的那一行不动，保存后回到光标处。光标所在的一段可以“设为标题”（从这里拆成新的一章），认错的标题可以“转为正文”（并回上一章）
- **启动后继续上次阅读**（设置里可关）
- **首页**：猫 + 今日阅读 + 继续阅读；读满 30 分钟猫头上长出一片叶子
- **统计 / 时间轴 / 猫园 / 桌面小组件**、深色模式

## 构建

```powershell
$env:JAVA_HOME = 'D:\Program\Android\Android Studio\jbr'
.\gradlew.bat :app:assembleRelease --offline
```

产物在 `app\build\outputs\apk\release\app-release.apk`，用本机 debug 签名，可直接安装。

仓库里没有字体文件，直接构建也能用，只是“霞鹜文楷”“仓耳今楷”会显示成系统字体。要带上字体，先按下面“字体”一节准备好。

### 发行包

两款楷体放在 `app/src/main/assets-private/`、小马宝莉放在 `app/src/main/res-private/`，都不进仓库。2.0.8 起 GitHub Release 里附的是作者自用的完整版（带这两样，只作个人存档、不作商用），App 里的「检查更新」下载的就是 Release 附的包。

要构建不带这两样的公开版，加 `-Ppublic`：

```powershell
.\gradlew.bat :app:assembleRelease --offline -Ppublic
```

## 代码结构

- `data/` 书架、设置、阅读记录（JSON 存在应用私有目录），`Importer` / `TxtParser` / `Epub` 负责导入，`Dict` 查词和选词
- `ui/reader/Paginator.kt` 按章排版分页：长章按段落切块，段距用段落间的占位小段落，两端对齐按行补字间距（不用系统的两端对齐：Android 15 起它撑开字距但取字位置的接口不算这部分，长按会偏）
- `ui/reader/ReaderScreen.kt` 阅读页、上下滚动、长按；`Selection.kt` 选字浮层和字典卡片；`EditPage.kt` 编辑本章：只有光标所在的一段是输入框，其余各段照阅读页排好不动（整章一个输入框时每打一个字都要重排整章，几千字的章节会卡），回车拆段、段首退格并段在输入框里处理
- `ui/components/Mascot.kt` 猫的画稿（200×200 坐标），`Kit.kt` 按钮、胶囊、滑块、分段控件、弹层等
- `ui/screens/` 首页、书架、统计、时间轴、猫园、设置、商城、装扮、成就、备份
- `data/Profile.kt` 叶子、已拥有的东西、装扮和成就（存在 `profile.json`）；`Shop.kt` 读 `assets/shop.json` 里的商品目录；`Backup.kt` 本地 zip 和 WebDAV；`AppIcon.kt` 用清单里的三个 activity-alias 切换桌面图标
- `ui/components/Creature.kt` 画商城动物和身上的饰品
- `data/Updates.kt` 检查更新：读 GitHub 上最新的 Release，下载附的安装包交给系统安装；`ui/screens/UpdateSheet.kt` 新版本弹层
- `tools/treasure.py` 镇店之宝金猪皇和 8 件神装；`tools/front_cat_anchors.py` 空叶三只正脸猫的饰品位置
- `ui/components/Scene.kt` 画猫园背景、路牌上的字和节日挂件（猫园、商城、装扮共用）
